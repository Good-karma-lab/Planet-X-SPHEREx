# Filter curves

Transmission curves (wavelength in Å, relative transmission) from the SVO Filter Profile Service
(https://svo2.cab.inta-csic.es/theory/fps/), used to average a SPHEREx spectrum under the 2MASS J, H, Ks and WISE W1, W2 bands for
the catalogue check of the Spectrum tab (`service/catalogue_check.py`).
