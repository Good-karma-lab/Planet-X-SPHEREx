# Super Intelligence (SI) use disclosure

**Statement for the project page:**

This project was built with AI coding assistants (Anthropic's Claude Code agents) working under the direction of our team. People on
the team set the goals and the rules, chose between designs, reviewed every result by looking at the pictures and clicking through the
tool, and decided what to keep. The agents wrote most of the code (the Python service and analysis, the web interface), the
documentation and the method write-up, ran the validation scripts and drafted these submission texts; a human reviewed and edited them.

The images and videos the tool shows are **not AI-generated**: they are computed deterministically by our code from real NASA SPHEREx
exposures (and archive images from DSS2, 2MASS and AllWISE, credited on screen). No generative image or video model was used for
any picture or figure of the tool. The 30-second demo video is the one exception: it contains two AI-generated clips (a space telescope in orbit and a flying star, made with Google Gemini), each marked "AI-generated" on screen, an AI voice-over and sound effects (ElevenLabs) and CC0 music ("Transmission", Dark Sci-Fi Audio Pack, OpenGameArt). Every sky image in the video and in the tool is real SPHEREx data. No NASA logo or insignia appears in any generated content.

AI-written code and text are acknowledged here and in the repository (commit messages carry a co-author line for the AI assistant).

**Notes for the user (not for the page):**
- Space Apps asks that SI-generated images or videos carry a visible watermark and that SI-generated code or data be acknowledged
  in text or metadata (Project Submission Guide, checked 2026-11-14; "SI" there means "Super Intelligence").
  Our pictures are computed renderings of data, not generated media; if the demo video uses any AI voice, AI-generated graphics or AI
  editing, that part needs the watermark.
- Keep NASA logos out of the slides and video unless the rules allow them.
