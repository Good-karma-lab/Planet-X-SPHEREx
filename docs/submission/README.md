- [ ] Team name, members, local event filled in (the user)
- [ ] Project name chosen
- [ ] Link to final project: public URL, opens without login; repository public or the link removed
- [ ] Demo: video ≤ 30 s in English (or English subtitles), hosted publicly — or ≤ 7 slides including the title
- [ ] Every picture in the demo is a recording of the tool on real data; any AI-generated media carries a visible watermark

- [ ] NASA data listed (at least one NASA resource); partner data (ESA Gaia) listed; references listed
- [ ] No NASA logo in generated content
- [ ] Claims on the page match what the deployed tool shows (trim the "how it was checked" list if needed)
- [ ] Submitted before 23:59 local time on Nov 15
