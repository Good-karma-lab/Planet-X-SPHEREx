# 2.7 Validation targets

The numbers the running system must reproduce. They become the automated validation suite (`validation/`, section 5.11 of the
architecture): each row is one check with a tolerance; the suite runs against the live archive on demand and nightly on the server, and
writes a dated report (`docs/validation/YYYY-MM-DD.md`). "Research" is the value measured in the research phase; the tolerance is a
judgement and the report always states the value obtained. A row that cannot be met blocks its milestone until the cause is found.
